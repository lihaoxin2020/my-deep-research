# Deep Research Web App

A web application for conducting deep research using various LLM providers like OpenAI, Anthropic, and Google.

## Features

- Conduct comprehensive research on any topic
- Support for multiple LLM providers (OpenAI, Anthropic, Google)
- User-provided API keys for secure access
- Research history tracking
- Customizable research depth

## Tech Stack

- React with TypeScript
- Vite for fast development and building
- Chakra UI for responsive and accessible components
- React Router for navigation
- Axios for API requests
- Vitest and Testing Library for testing

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/lihaoxin2020/my-deep-research.git
cd my-deep-research
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm run dev
```

4. Open your browser and navigate to http://localhost:12000

### Building for Production

```bash
npm run build
```

### Running Tests

```bash
npm test
```

## Usage

1. Configure your API settings in the Settings page
2. Enter your research query on the home page
3. Adjust the research depth if needed
4. Click "Start Research" to begin
5. View your research results and sources
6. Access your research history in the History page
